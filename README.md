## Activity Description

This activity introduces the basic technologies
used in creating a Stack and Queue Simulator Web App,
including HTML, CSS, JavaScript, Bootstrap, and jQuery.

The simulator demonstrates the Last In,
First Out (LIFO) principle of a stack and First In, First Out (FIFO) principle of a queue.
The starter project contains Push, Pop,
Peek, and Clear buttons that will be
connected during the demonstration.



## Files

* style.css - Webpage design
* queue.js - Queue operations



stack-simulator:
